# EduNext 🎓 – E-learning Platform

EduNext est une plateforme moderne d'apprentissage en ligne développée avec **Spring Boot**, **Angular**, et sécurisée avec **Keycloak** & **JWT**. Elle prend en charge plusieurs rôles utilisateurs (Learner, Teacher, Admin) et propose une architecture modulaire, évolutive et sécurisée.

---

## 🚀 Fonctionnalités principales

- 🔐 Authentification et autorisation via **Keycloak** (OpenID Connect)
- 🎯 Gestion des rôles : `Admin`, `Learner`, `Teacher`, `Research`
- 🧾 Inscription personnalisée par rôle (plus de détails requis pour les Teachers)
- 🛡️ Intégration JWT personnalisée (avec `JwtAuthConverter`)
- 👨‍🏫 Back-office et front-office séparés selon les rôles
- 📸 Photo de profil de l’utilisateur connecté avec menu déroulant
- 🧠 Statistiques utilisateur via Chart.js (bannis, actifs, répartition)
- 🔄 Fonctionnalité de bannissement / débannissement d'utilisateurs
- ✉️ Réinitialisation de mot de passe via email & SMS
- 🌍 Support multilingue (gestion de langue transactionnelle)
- 🧪 Intégration Google Sign-in avec adaptation au système JWT


---

## 🛠️ Technologies utilisées

### Backend
- Java 17
- Spring Boot 3+
- Spring Security + JWT
- Keycloak (serveur d'identité)
- MySQL
- Twilio (envoi de SMS)
- JavaMailSender

### Frontend
- Angular 16+
- Angular Material / Tailwind CSS
- Chart.js (statistiques dynamiques)
- Reactive Forms
- Authentification avec JWT et Google Sign-In
